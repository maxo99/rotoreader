# RotoReader

RotoReader is a Python library designed to facilitate aggregation of sports news and data from various online sources. It provides tools to scrape, parse, and analyze sports-related content, making it easier for developers and enthusiasts to access up-to-date information.

## Features

- Scrape sports news articles from multiple websites
- Semantic retrieval of sports data.

## Components

- API Framework: FastAPI
- Vector Store: PGVector

## Deployment

- Docker: Containerized deployment for easy setup and scaling.
- Docker Componse: PGVector and FastAPI integration for seamless operation.
